🌐 Step 1 — Cloudflare Worker (Free API)
100% Free
Why Cloudflare? Free forever, no credit card, handles auth with SharePoint via Microsoft Graph API. 100,000 free requests per day.
1
Sign up at cloudflare.com
Create a free account at cloudflare.com — no credit card needed. Click Workers & Pages.
2
Create a new Worker
Click Create Application → Create Worker → give it a name like procurement-api → Deploy.
3
Paste the Worker code
Click Edit Code, paste the contents of cloudflare-worker.js (download below), click Save & Deploy.
4
Set environment variables
In Worker Settings → Variables, add:

TENANT_ID = (your Azure Tenant ID) CLIENT_ID = (your Azure App Client ID) CLIENT_SECRET = (your Azure App Client Secret — never put real value in HTML!) SITE_ID = (your SharePoint Site ID)
🔒 Security tip: Never write real credentials in this HTML file. Keep your Client Secret only in Cloudflare Worker environment variables — it is encrypted there and never exposed to users.
5
Copy your Worker URL
Your free URL will be:
https://procurement-api.YOUR-NAME.workers.dev
Paste it in Settings tab above.
📄 Step 2 — Host Dashboard Free
🌐 Option A: GitHub Pages
Upload index.html to GitHub repo, enable Pages in Settings. Free forever at username.github.io/repo
📄 Option B: SharePoint Page
Upload the HTML to your SharePoint Documents library. Share the direct link — works in any browser, no login needed if link is shared externally.
⚡ Option C: Cloudflare Pages
Upload to Cloudflare Pages (same dashboard). Free, fast CDN globally. Auto-deploys from GitHub.
1
GitHub Pages (Easiest)
Create repo at github.com, upload index.html, go to Settings → Pages → Deploy from main branch.
git init git add index.html git commit -m "Deploy dashboard" git push origin main
2
SharePoint Hosting
Go to your SharePoint site → Documents → Upload 04_dashboard_final.html. Right-click → Copy Link → Share with team.
3
Enter Worker URL in Settings
Wherever the HTML is hosted, open it in browser → Settings tab → paste your Cloudflare Worker URL → Save & Test. Done!
